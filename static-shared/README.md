# static-shared — Cortex-M static-loader SCL + tests

A self-contained subset of `shared-loaders-cortex-m-qemu` holding only the
**static** shared-library loader family for Cortex-M (ARM32):

| Target | What it is |
|---|---|
| `scl::static` | ELF32 static patcher: load a `-fPIC` `.so`, patch its GOT/PLT and main's GOT, run `.init_array`, resolve symbols. Byte-exact unload (patch journal), single/multi-thread + global-dynamic TLS (`__tls_get_addr`), `RTLD_LOCAL`/`RTLD_GLOBAL`, reference counting, DT_NEEDED auto-load, reentrancy hooks. |
| `scl::xip-static` | Execute-in-place flavour: R-X segment runs from flash, RW (GOT/data/bss) is copied to RAM (r10 PIC base). |
| `xip::nopic`¹ | Fixed-address alternative: modules are `-fno-pic -mlong-calls` linked at fixed VAs, so main calls them by name with no r10/GOT/PLT (`docs/xip-static-no-pic.md`). |
| `common-elf-reader` | Vendored ELF32 reader/parser the loaders build against (source, no `.a`). |

Everything is an INTERFACE "source code library" — no archives; consumers compile
the sources with their own flags.

> ¹ The no-pic flavour has **no standalone CMake alias** — there is no
> `scl::xip-nopic` target. Consume it by compiling `src/xip/static/nopic.cpp`
> into your firmware and linking `scl::xip-common` (see `docs/build-and-test.md`
> and the `test-xip/test-xip-static-no-pic*` apps).

## Layout

```
src/static/          scl::static loader (elf-reader, shlib-loader, module, tls)
src/xip/             scl::xip-common + xip-static adapter + xip::nopic (fixed-address)
include/static/      scl::static public headers
include/xip/         XIP headers (incl. static/{adapter,nopic}.hpp)
include/scl/         shared port headers (barrier, image-memory, link-context, ...)
common-elf-reader/   the ELF32 parser (vendored)
test-static/         static loader firmware apps + fixtures
test-xip/            XIP static firmware apps (static/semihosting, static-direct,
                     static-no-pic, static-no-pic-simple, interrupt-static,
                     interrupt-static-direct, static/spi-flash)
test-flatfs/         flat-fs flash filesystem dependency used by the XIP apps to
                     provision/store .so blobs on-chip (src/fs-archive.cpp,
                     flash-prog.c + headers) — no dynamic loader involved
test-flatfs-spi/     SPI-flash (W25Q64) headers for the static/spi-flash test
test/platforms/      board (weact/nucleo), board-hosted, qemu-f411re platforms
test/fixtures/       shared prebuilt PIC fixtures
```

## Boards

`SCL_BOARD` (default `weact`) selects the target; each app supports:

- `weact`   — WEACT-F411CE (BlackPill), CMSIS-DAP
- `nucleo`  — NUCLEO-F411RE, ST-LINK
- `qemu`    — qemu-system-arm (`netduinoplus2` machine), no hardware needed

## Build + run

```sh
# One shot (build + flash + run on the board), per tree:
./test-static/build-and-run.sh <weact|nucleo|qemu> <static|static-cpp|static-direct|drv>
./test-xip/build-and-run.sh     <weact|nucleo|qemu> <static/semihosting|static-direct|static-no-pic|static-no-pic-simple|interrupt-static|interrupt-static-direct|static/spi-flash>

# Or configure manually:
cmake -S test-static/test-static-direct -B build \
      -DCMAKE_TOOLCHAIN_FILE=test-static/test-static-direct/cmake/arm-none-eabi.cmake \
      -DSCL_PLATFORM=board -DSCL_BOARD=weact
cmake --build build
```

Prerequisites: `arm-none-eabi-gcc` and `openocd` (xPack installs auto-detected by
`tools-config.sh`); `qemu-system-arm` for the qemu targets.

## Notes

- `test-xip/fixtures/`, `test-static/*/build/` and all `*.so`/`*.bin`/`*.hex`
  outside `test/fixtures/` are generated by the build scripts and gitignored.
- `test/fixtures/*.so` are committed prebuilt PIC fixtures used at runtime.
- SPI tests (`drv`, `static/spi-flash`) need the W25Q64 wired on the WeAct board;
  they are WeAct-only (no qemu).
